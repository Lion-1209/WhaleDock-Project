# 鲸屿 WhaleDock · 显示协议 v1.1（已冻结）

> 状态：**v1 冻结**（2026-09-21）；**v1.1 兼容追加**（2026-09-21，追加项见附录 D，消费端靠"未知字段忽略"平滑兼容）。冻结后：新增字段/新增 Widget 类型走 **v1.x 兼容扩展**；任何破坏性改动走 **v2**，禁止原地改语义。
> 消费方三方一致：固件 Widget 引擎（`firmware/src/app/`）、上位机布局编辑器、网页模拟器（console/simulator.html）。对协议的疑问以本文为准，设计文档§显示协议为历史草案（差异见附录 C）。

## 0. 总则

- 上位机产出布局 JSON → 下发到设备（Web Serial / 设备 HTTP API）→ 设备持久化到 LittleFS（`/layout.json`）→ 每个整点"拉数据 → 渲染 → 全刷"。
- 屏幕固定 800×480 四色（黑/白/红/黄），全刷约 21s，刷新封顶 ≤1 次/小时。
- 一个 JSON 要么是 **Widget 布局**（`layout`），要么是**位图通道**（`display`），二选一。
- 所有 JSON 字段名、枚举值均为 ASCII；文案内容为 UTF-8。

## 1. 顶层结构

```json
{
  "version": 1,
  "dataSources": [ ... ],
  "resources":  [ ... ],
  "fonts":      [ ... ],
  "layout":     { "resolution": [800, 480], "widgets": [ ... ] },
  "remoteConfig": null
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `version` | ✓ | 恒为 `1`；非 1 整体拒绝 |
| `dataSources` | − | 数据源声明，Widget 按 `source` 引用；可为空（纯时钟/图文布局） |
| `resources` | − | 内联资源（图片），id 供 image/pet Widget 引用 |
| `fonts` | − | 中文字库子集，见 §6 |
| `layout` | 与 display 二选一 | Widget 布局 |
| `display` | 与 layout 二选一 | 位图通道，见 §7 |
| `remoteConfig` | − | v1 保留字段，恒为 `null`（二期远程换模板） |

## 2. 数据源 dataSources

```json
{ "id": "gh",  "type": "github.user", "params": { "user": "datawhalechina" }, "token": "" }
{ "id": "repo","type": "github.repo", "params": { "owner": "datawhalechina", "repo": "leeml-notes" }, "token": "" }
```

| 字段 | 说明 |
|---|---|
| `id` | 布局内唯一，Widget 的 `source` 引用它 |
| `type` | v1 仅 `github.user` / `github.repo` |
| `token` | 可选；优先级 **dataSource.token > 设备全局配置 > 匿名**。不回显、不落日志 |
| `params` | 见端点映射 |

**端点映射（v1 全部 REST，匿名限额 60 次/时/IP，配 token 5000/时）**：

| type | 端点 | 缓存文件（设备） |
|---|---|---|
| `github.user` | `GET /users/{user}` | `/cache/user.json` |
| `github.repo` | `GET /repos/{owner}/{repo}` | `/cache/repo.json` |
| `github.repo`（提交序列） | `GET /repos/{owner}/{repo}/stats/participation` | `/cache/commits.json` |

> 注意：`/stats/commit-activity` 已废弃（认证访问也 404），提交序列一律走 `/stats/participation`（52 周数组，设备取最近 12 周）。

## 3. 槽位 slot（几何表，三方一致）

800×480，内容边距 12px，象限间距 12px，底部 ticker 通栏高 48px：

| slot | x | y | w | h | 说明 |
|---|---|---|---|---|---|
| `tl` | 12 | 12 | 382 | 192 | 左上象限 |
| `tr` | 406 | 12 | 382 | 192 | 右上象限 |
| `bl` | 12 | 216 | 382 | 192 | 左下象限 |
| `br` | 406 | 216 | 382 | 192 | 右下象限 |
| `ticker` | 12 | 420 | 776 | 48 | 底部通栏 |

- 每个 slot 至多一个 Widget（slot 即占位键）。
- `ticker` 槽只允许 `ticker` / `text` 类型；象限槽任意类型。
- v1 为槽位制；自由矩形摆放留给 v2。
- **v1.1 `slotRect` 覆写**（可选）：`{x,y,w,h}` 整数像素，须完整落在 800×480 内（校验规则 12）；给出时覆盖槽位默认几何（概念图复刻等横带构图用），`slot` 仍必填（占位键与缺省回退）。

## 4. Widget 类型注册表（v1 内置 8 种）

通用字段：`slot`、`type`、可选 `color`（`black|red|yellow`，默认 `black`）。二开 = 固件实现新类型的 `draw()` + 类型声明（v1.x 兼容新增）。

| type | 专有字段 | 数据需求 | 说明 |
|---|---|---|---|
| `clock` | `calendar`（bool，默认 true） | NTP 系统时间 | 时钟+日期星期；`calendar: true` 画当月整月日历阵（Su–Sa 表头+日期，今日红圈）；不占数据源 |
| `stats` | `source`✓、`fields`✓、`labels` | github.user / github.repo | 数字统计。字段白名单：`public_repos`、`followers`、`stars`、`forks`；`labels` 与 fields 等长中文标签 |
| `barChart` | `source`✓、`weeks`（默认 12）、`title`、`goal`（数值）、`goalColor`（默认 yellow） | github.repo（participation） | 周/月提交柱状图；`goal` 画目标横线 |
| `pet` | `res`（默认 `whale_pixel`） | 无 | 像素鲸鱼桌宠，小时级换帧；`whale_pixel` 为固件内置资源 |
| `text` | `text`✓、`size`（`s|m|l`，默认 m） | 无 | 自由图文 |
| `image` | `resBW`✓、`resR`、`resY` | 无 | 内联图片，三平面各自可选；黑白图抖动由编辑器完成 |
| `qr` | `text`✓、size（px 边长，默认 128） | 无 | 二维码**恒黑色**（红色扫码不可靠），无 color 字段 |
| `ticker` | `text`✓ | 无 | 底部通栏文案（如 "Keep coding. Keep shipping."） |
| `heatMap`（v1.1） | `source`✓、`title` | github.repo（按日贡献） | 贡献热力图（概念图主视觉）。**数据按日，REST 不可得**：一期模拟器/编辑器用演示数据，设备端待二期 GraphQL+token；格子统一等大、选择性填充：0=空框、1/2/3=实心黑、4=实心红（四色屏无灰阶，密度信息由出现频率承载）；标题左上、月份轴在点阵上方、点阵按区宽自适应铺满；Less/More 图例在点阵下方左缘 |

通用可选字段（v1.1 追加）：`align`（`left|center|right`，用于 clock/text 块级对齐）；`stats.variant`（`list|chips`，chips = 横排小卡：icon+标签+数值，红色 icon 由渲染器按概念图规则分布）。

## 5. 颜色模型

- 枚举：`black | red | yellow`（白为底色，不可选）。
- **红为一级强调**（合计面积 < 5%），黄为二级强调（目标线、次级高亮、点缀）。
- `qr` 恒黑；禁止大面积深色块（四色屏残影特性），模板规范由编辑器把关。

## 6. 字体 fonts（中文字库子集随布局下发）

```json
{ "id": "txt12", "size": 12, "glyphs": "<b64 u8g2 字体子集>" }
```

- 文本 Widget 可用 `font` 字段引用 `fonts[].id`；未引用时用设备默认字体。
- 子集由**编辑器按布局用字生成**，缺字在编辑器阶段拦截（设备不做缺字回退渲染）。
- `glyphs` 的具体打包格式在 B2 实现时定稿（v1 冻结的是承载结构；格式定稿以 v1.1 备注追加，不改字段）。assets 分区可预置全量字库作离线兜底。

## 7. 位图通道 display（自由创作/照片）

```json
{ "version": 1, "display": { "bitmapBW": "<b64>", "bitmapRed": "<b64>", "bitmapYellow": "<b64>" } }
```

- 三个平面各 **48000 字节**（800×480÷8），b64 编码，均可省略（省略 = 全白）。
- 灰度照片的抖动只作用于黑白平面；编辑器预览 = 最终效果（1:1）。
- 位图通道下发后立即上屏（手动触发，不占整点节奏）。

## 8. 刷新与缓存

- 设备整点齐刷：NTP 对时 → 拉全部 dataSources → 渲染 → 全刷；封顶 ≤1 次/小时。
- 拉取失败用 LittleFS 缓存（§2 表）兜底渲染"最后一版数据"；全部失效渲染占位布局。
- 布局 JSON 变更本身不触发刷新，等下一个整点（或 CLI/HTTP 手动 `pipe` + 刷屏）。

## 9. 校验规则（固件/编辑器/模拟器三方同实现）

1. `version` 必须为 `1`。
2. `layout` 与 `display` 恰有一个。
3. `layout.resolution` 必须为 `[800, 480]`。
4. `slot` ∈ 五个合法值；每槽至多一个 Widget；`ticker` 槽仅 `ticker|text`。
5. `type` 必须已注册。
6. `barChart`/`heatMap` 的 `source` 必须存在于 `dataSources`；`stats` 可省略 `source`（= **聚合全部数据源取字段**，字段名须无歧义；给出时仍须已声明）。
7. `color`/`goalColor` ∈ `{black, red, yellow}`；`qr` 不带 color。
8. `stats.fields` 非空且全部在白名单内；`labels`（若给出）与 fields 等长。
9. 位图平面 b64 解码后恰为 48000 字节。
10. **未知字段一律忽略**（前向兼容的根基）。
11. token 生效优先级：`dataSource.token` > 设备全局 > 匿名。
12. **（v1.1）`slotRect` 若给出**：四值均为整数、`x,y ≥ 0`、`w,h > 0`、`x+w ≤ 800`、`y+h ≤ 480`。

## 10. 下发与确认

- 通道：Web Serial（CLI `layout` 命令族，B3 实现）/ 设备 HTTP `POST /api/layout`（D3 编辑器接入）。
- 设备校验通过才落盘 `/layout.json`，返回 `{ "ok": true, "widgets": N, "sources": M }`；失败返回 `{ "ok": false, "errors": [...] }`（对应 §9 规则编号与描述）。

## 11. 完整示例

**v1.1 推荐示例 = 概念图 v2（鲸屿形态）屏幕版式复刻**（模拟器"加载概念图示例"同款，slotRect 横带构图；鲸鱼 = `鲸鱼概念图素材` 鲸鱼区经 `tools/pixelize.html` 转 220×192 1bpp 位图，以 `image` 类型内联）：

```json
{
  "version": 1,
  "dataSources": [
    { "id": "gh",   "type": "github.user", "params": { "user": "datawhalechina" } },
    { "id": "repo", "type": "github.repo", "params": { "owner": "datawhalechina", "repo": "leeml-notes" } }
  ],
  "resources": [
    { "id": "whale_logo", "w": 220, "h": 192,
      "data": "<base64 串约 7.2KB：datawhalelogo.png 鲸鱼区（原图 y176-667）缩放 220 宽、阈值 200 二值化、1bpp MSB-first 打包；眼睛瞳孔手工修 3×3 像素；完整串见 console/js/sim.js 的 SAMPLE>" }
  ],
  "layout": {
    "resolution": [800, 480],
    "widgets": [
      { "slot": "tl", "slotRect": { "x": 12, "y": 14, "w": 330, "h": 264 },
        "type": "image", "resBW": "whale_logo" },
      { "slot": "tr", "slotRect": { "x": 354, "y": 14, "w": 426, "h": 264 },
        "type": "clock", "calendar": true, "align": "right" },
      { "slot": "bl", "slotRect": { "x": 12, "y": 282, "w": 500, "h": 160 },
        "type": "heatMap", "source": "repo", "title": "GitHub Contribution" },
      { "slot": "br", "slotRect": { "x": 524, "y": 282, "w": 264, "h": 160 },
        "type": "stats", "variant": "chips",
        "fields": ["public_repos", "stars", "forks", "followers"],
        "labels": ["Repositories", "Stars", "Forks", "Followers"] },
      { "slot": "ticker", "slotRect": { "x": 500, "y": 448, "w": 288, "h": 20 },
        "type": "text", "size": "s", "align": "right", "text": "Keep coding. Keep shipping." }
    ]
  }
}
```

> 布局说明：上层 = 鲸鱼（左）+ 时钟（右）；中层左 = 热力图（标题左上、月份轴在点阵上方、点阵按区宽自适应铺满），中层右 = stats 竖卡（渲染器按 slotRect 宽高比自动选择横排/竖卡形态）；右下 = ticker 标语。

## 附录 B · 资源 resources（内联图片）

```json
{ "id": "logo_bw", "type": "img_bw", "w": 100, "h": 60, "data": "<b64>" }
```

- `type`：`img_bw`（1bit/px）、`img_r`、`img_y`；`data` 字节数须等于 `ceil(w/8)*h`。
- 单资源建议 ≤ 16KB（b64 前），总量由编辑器控制（LittleFS 布局文件 < 200KB）。
- 固件内置资源（如 `whale_pixel`）不随布局下发。
