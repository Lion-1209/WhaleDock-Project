    01 · 通道 CHANNELS — 串口 / WI-FI / 局域网
    

  
    
    
    设备连接 SERIAL
    
    
    首次使用点「添加串口…」，按引导选中 USB 串行设备 (COM…) 即可——授权一生只需一次。USB-C 插 DevKitC-1 标 "USB" 的口；连接前关闭占用串口的程序。
    
    
    
    
      
      
      
      
    
    
    
    
      
    
        
    浏览器串口授权（仅首次）
    
        
    点「继续」后，浏览器会弹出它自己的串口选择框：
    选择名称为 USB 串行设备 (COM…) 的端口并点「连接」。
    这是浏览器的安全机制，授权一次后本页将直接连接，不再出现。
    
        
    
          
          
        
    
      
    
    
    
  
    

  
    
    
    Wi-Fi 配网 PROVISION
    
    
    海里还没有信号——插上 USB 连接设备后，这里显示凭据状态。
    
    
    
      
      
      
      
    SSID / 密码暂不能包含英文逗号（串口 CLI 协议限制）。ESP32-S3 仅支持 2.4GHz。
    
      
    
        
        
        
        
      
    
    
    
    
    
  
    

  
    
    
    局域网设备 HTTP未连接
    
    
    串口之外的 Wi-Fi 直连通道（设备自动注册 whaledock-xxxx.local）。状态/流水/OTA/重启均可走网络；日志仍走串口。与串口通道互不干扰，烧录/升级不再需要断开串口。
