设备连接

首次使用点「添加串口…」，按引导在浏览器授权框中选中 "USB 串行设备 (COM…)"——此步是浏览器安全要求，一生只需一次；之后的选择、切换、重连全部在本页完成。USB-C 插 DevKitC-1 标 "USB" 的口；连接前关闭占用 COM 口的程序（如 VS Code 串口监视）。

浏览器串口授权（仅首次）

点「继续」后，浏览器会弹出它自己的串口选择框：
选择名称为 USB 串行设备 (COM…) 的端口并点「连接」。
这是浏览器的安全机制，授权一次后本页将直接连接，不再出现。
